# Appinapp - macOS customization tool

[Appinapp](appinapp.mutawirr.uz) is desktop (currently macOS) customization tool which is turns small JSX codes into live widgets that sit on your home screen.

[Quick Start](appinapp.mutawirr.uz) | [Features](appinapp.mutawirr.uz)
